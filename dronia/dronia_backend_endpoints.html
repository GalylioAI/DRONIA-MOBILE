DronIA — Complete API Reference

For the Flutter mobile developer — all active endpoints on the VPS

Architecture Overview

ML Backend (FastAPI)
https://dronia-tunisie.tn/ml-api
Python · AI models (EfficientNet + YOLO11s)
App Backend (Next.js)
https://dronia-tunisie.tn/api
Node.js · Auth, Weather, History, DB, Field Monitoring
Database
MongoDB Atlas
Cloud database · users, predictions, insects
Important for Flutter: There are two separate backends. The ML models are at /ml-api/... (FastAPI). Everything else — auth, weather, field monitoring, advisor — is at /api/... (Next.js). Both are on the same domain.

POST /classify/base64 ML Plant disease detection (EfficientNet — 38 classes)
Full URL
https://dronia-tunisie.tn/ml-api/classify/base64

Classifies plant diseases from a base64-encoded image. EfficientNet trained on PlantVillage (38 classes: tomato, potato, corn, apple, olive, grapes, etc.). Results returned in French.

FieldTypeRequiredDescription
imagestringREQUIREDBase64-encoded image (JPEG or PNG)
zonesstringoptionalJSON string of bounding box zones — rarely used

Example Response:

{
  "success": true,
  "predictions": [
    {
      "class": "Tomato___Late_blight",
      "confidence": 0.87,
      "class_french": "Mildiou (Tomate)",
      "treatment": "Appliquer des fongicides systemiques...",
      "prevention": "Plants certifies, eviter l'humidite excessive..."
    }
  ],
  "model_used": "EfficientNet-b0",
  "processing_time_ms": 234
}

Flutter / Dart example:

import 'dart:convert';
import 'dart:io';
import 'package:http/http.dart' as http;

Future<Map<String, dynamic>> classifyPlant(File imageFile) async {
  final bytes = await imageFile.readAsBytes();
  final base64Img = base64Encode(bytes);

  final request = http.MultipartRequest(
    'POST',
    Uri.parse('https://dronia-tunisie.tn/ml-api/classify/base64'),
  );
  request.fields['image'] = base64Img;

  final response = await request.send();
  final body = await response.stream.bytesToString();
  return jsonDecode(body);
}
POST /predict/insects ML Insect detection — file upload
Full URL
https://dronia-tunisie.tn/ml-api/predict/insects

Detects and identifies insects from an uploaded image. Uses YOLO11s fine-tuned on IP102 dataset (102 agricultural pest species). Returns bounding boxes and French names.

FieldTypeRequiredDescription
fileFileREQUIREDImage file (JPEG or PNG) — multipart upload
confidencefloatoptionalDetection threshold (default: 0.25)
ioufloatoptionalIoU threshold for NMS (default: 0.45)
⚠ First call is slow (~30s): The YOLO11s insect model lazy-loads on the first request. Subsequent calls are fast. Show a loading indicator on first use.

Example Response:

{
  "success": true,
  "detections": [
    {
      "class": "aphid",
      "class_french": "Puceron",
      "confidence": 0.92,
      "bbox": [120, 80, 240, 160]
    }
  ],
  "total_detections": 1,
  "image_with_boxes": "<base64 image with bounding boxes drawn>"
}

Forgot Password Flow — 3-step OTP via Email
✨ Forgot password is fully implemented. It uses a 3-step OTP flow via email (not SMS). The OTP is a 6-digit code sent to the user's email, valid for 15 minutes.
STEP 1
POST /api/auth/forgot-password
Send OTP code to email
STEP 2
POST /api/auth/verify-otp
Verify the 6-digit code
STEP 3
POST /api/auth/reset-password
Set new password
POST /api/auth/forgot-password AUTH ✨ New Step 1 — Send OTP code to email
Full URL
https://dronia-tunisie.tn/api/auth/forgot-password

Sends a 6-digit OTP code to the user's email. OTP is valid for 15 minutes and is stored hashed in the database. Always returns success to prevent email enumeration attacks.

FieldTypeRequiredDescription
emailstringREQUIREDThe user's registered email address

Response (always 200 — does not reveal if email exists):

{ "success": true, "message": "Si cet e-mail existe, un code a été envoyé." }
POST /api/auth/verify-otp AUTH ✨ New Step 2 — Verify the 6-digit OTP code
Full URL
https://dronia-tunisie.tn/api/auth/verify-otp

Verifies the OTP code entered by the user. If valid, marks the session as OTP-verified so the user can proceed to reset the password. Must be called before reset-password.

FieldTypeRequiredDescription
emailstringREQUIREDThe user's email address
otpstringREQUIREDThe 6-digit code from the email

Success Response (200):

{ "success": true, "message": "Code vérifié. Vous pouvez maintenant réinitialiser votre mot de passe." }

Error responses:

{ "error": "Code OTP incorrect." }                        // wrong code
{ "error": "Le code OTP a expiré. Veuillez en demander un nouveau." }  // after 15 min
{ "error": "Code invalide ou expiré." }                     // no OTP was requested
POST /api/auth/reset-password AUTH ✨ New Step 3 — Set a new password
Full URL
https://dronia-tunisie.tn/api/auth/reset-password

Sets a new password. Only works if the OTP was verified in step 2. Clears all OTP fields after success. The user can then log in with the new password.

FieldTypeRequiredDescription
emailstringREQUIREDThe user's email address
newPasswordstringREQUIREDNew password (minimum 6 characters)

Success Response (200):

{ "success": true, "message": "Mot de passe réinitialisé avec succès. Vous pouvez maintenant vous connecter." }

Error if OTP not verified first (403):

{ "error": "Vous devez d'abord vérifier le code OTP." }

Flutter flow example:

// Step 1: request OTP
await http.post(
  Uri.parse('https://dronia-tunisie.tn/api/auth/forgot-password'),
  headers: {'Content-Type': 'application/json'},
  body: jsonEncode({'email': userEmail}),
);

// Step 2: verify code the user typed
final verifyRes = await http.post(
  Uri.parse('https://dronia-tunisie.tn/api/auth/verify-otp'),
  headers: {'Content-Type': 'application/json'},
  body: jsonEncode({'email': userEmail, 'otp': otpCode}),
);
if (jsonDecode(verifyRes.body)['success'] == true) {
  // Step 3: set new password
  await http.post(
    Uri.parse('https://dronia-tunisie.tn/api/auth/reset-password'),
    headers: {'Content-Type': 'application/json'},
    body: jsonEncode({'email': userEmail, 'newPassword': newPassword}),
  );
}

Field Monitoring — Next.js (https://dronia-tunisie.tn/api/field-monitoring) ✨ New
✨ New endpoint. Provides Sentinel-2 satellite vegetation indices, satellite heatmap imagery, weather data for a drawn polygon, and soil moisture from Sentinel-1 radar. Powered by Sentinel Hub (Copernicus Data Space) — OAuth2 credentials are stored server-side.
All actions: POST to the same URL with a JSON body. The action field selects which data to fetch.
POST /api/field-monitoring FIELD Satellite vegetation indices (time series)
Full URL
https://dronia-tunisie.tn/api/field-monitoring

Action: "vegetation" — Returns daily statistics for the chosen index over the date range (Sentinel-2 L2A). Filters clouds ≤ 30%. Indices available: ndvi, ndre, msavi, reci, ndmi, ndwi.

Request body (JSON):

FieldTypeRequiredDescription
actionstringREQUIRED"vegetation"
polygonarrayREQUIREDArray of [lng, lat] pairs (≥3 points) closing the field shape
indexstringREQUIRED"ndvi" | "ndre" | "msavi" | "reci" | "ndmi" | "ndwi"
dateStartstringREQUIREDStart date YYYY-MM-DD
dateEndstringREQUIREDEnd date YYYY-MM-DD

Success Response:

POST /api/field-monitoring FIELD Satellite heatmap image (colorized PNG)
Full URL
https://dronia-tunisie.tn/api/field-monitoring

Action: "heatmap" — Returns a colorized PNG of the selected index, rendered using Sentinel Hub Process API. The color ramp maps: red → negative values, yellow → 0, lime → 0.5, dark-green → 1. The image bbox is returned to place it correctly on a map. Uses the most recent 30 days before dateEnd.

FieldTypeRequiredDescription
actionstringREQUIRED"heatmap"
polygonarrayREQUIREDArray of [lng, lat] pairs
indexstringREQUIRED"ndvi" | "ndre" | "msavi" | "reci" | "ndmi" | "ndwi"
dateEndstringREQUIREDEnd date YYYY-MM-DD (searches 30 days back from here)
dateStartstringoptionalNot used for heatmap — only dateEnd matters

Success Response:

{
  "success": true,
  "imageUrl": "data:image/png;base64,iVBORw0KGgo...",  // base64 PNG ~512px wide
  "bounds": {
    "minLng": 10.15,
    "maxLng": 10.22,
    "minLat": 36.78,
    "maxLat": 36.85
  }
}
Map overlay: Use bounds to place the image on a map (e.g. flutter_map OverlayImageLayer). The PNG covers the full bounding box rectangle — clip to the polygon shape on the client side if needed.
